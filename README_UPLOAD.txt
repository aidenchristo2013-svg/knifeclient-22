KNIFE CLIENT UPDATE (1.21.4)
1. Unzip this folder.
2. On GitHub: Add file -> Upload files. Select ALL files in this folder and drag them in.
3. Commit. Say yes to replacing files. Leave .github/workflows/main.yml alone.
4. Wait for the green tick in Actions, download the knifeclient-jar artifact, put the jar in mods.
5. In game: Right Shift. New pages: Render (skies, ESP, crosshair...), HUD, Utility.
   Waypoints: B = add, N = clear. Each new module has a Debug Overlay option if something looks off.
